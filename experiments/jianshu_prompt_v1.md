# 🔍 鉴书灵 Prompt v1 — 第一版图书鉴别提示词模板

> 这是 7 月开战时使用的**起点版本**，预计需要迭代到 v3-v5 才能稳定。

---

## 📋 使用流程

1. 准备 2 张图：
   - `reference_image`：已知的正版样本（你拍的 10 张特征图之一）
   - `user_image`：用户提供的待鉴别书的同一部位

2. 调用 Qwen-VL，传入 2 张图 + 下面的 Prompt

3. 让 AI 返回结构化 JSON 判断

---

## 🎯 Prompt 模板（核心版本）

```text
你是一位拥有 10 年经验的专业图书鉴定师，专门识别盗版图书。

我现在给你两张图片：
- 第一张：已知正版的【{feature_type}】特写
- 第二张：用户提供的同一本书、同一部位的特写

你的任务是对比这两张图，判断第二张图所代表的书是否为盗版。

【鉴别维度】（根据 6 年实战经验整理）

1. 文字层面
   - 文字边缘锯齿（喷墨打印 vs 胶印的核心区别 ⭐）
   - 文字粗细均匀度
   - 油墨晕染、断墨现象
   - 字体一致性（盗版常用相似字体替代）

2. 装帧层面
   - 烫金/烫银工艺是否一致
   - 纸张厚度与质感
   - 裁切边缘整齐度

3. 印刷层面
   - 色彩饱和度与还原度
   - 网点结构（盗版常见过粗或失真）
   - 暗部细节保留程度
   - 整体反差自然度

4. 用纸层面
   - 纸张白度
   - 纸张反光性（盗版常用更便宜的反光纸）

【输出要求】

请严格按照以下 JSON 格式输出，不要有任何额外说明文字：

{
  "verdict": "正版" | "疑似盗版" | "高度疑似盗版" | "无法判断",
  "confidence": 0.0-1.0 的数字,
  "similarity_score": 0.0-1.0 的数字（两张图整体相似度）,
  "differences": [
    {
      "dimension": "文字/装帧/印刷/用纸 其中之一",
      "observation": "具体观察到的差异（不超过 50 字）",
      "severity": "low" | "medium" | "high"
    }
  ],
  "reasoning": "用一段话总结你的判断依据（不超过 100 字）",
  "user_advice": "给用户的建议（不超过 50 字）"
}
```

## 🧪 测试计划

### 第 1 轮：单维度测试（Day 3-4）

| 测试编号 | 输入 | 期望 AI 抓到的差异 |
|---------|------|-----------------|
| T01 | 正版封面 vs 正版封面（同一张图） | similarity ≈ 1.0, verdict="正版" |
| T02 | 正版封面 vs 盗版封面 | 色彩饱和度差异 / 烫金缺失 |
| T03 | 正版文字 vs 盗版文字（喷墨） | **文字边缘锯齿** ⭐ 这是关键 |
| T04 | 正版书脊 vs 盗版书脊 | 烫金工艺差异 |
| T05 | 正版衬页 vs 盗版衬页 | 纸张厚度 / 颜色差异 |

### 第 2 轮：抗干扰测试（Day 5-6）

| 测试编号 | 干扰因素 | 期望 |
|---------|---------|------|
| T11 | 正版图片在弱光下拍 | AI 仍能判定为正版 |
| T12 | 盗版图片在强光下拍 | AI 仍能判定为盗版 |
| T13 | 两张图角度有偏差 | AI 不被欺骗 |
| T14 | 一张高清 + 一张模糊 | AI 输出"无法判断"而非乱猜 |

---

## 📊 评估指标

每一轮测试后，记录：

1. **准确率**：AI 判断与真实情况一致的比例
2. **置信度准度**：AI 给出高置信度时，准确率是否真的高
3. **理由质量**：AI 给的差异点是否真的是关键破绽
4. **稳定性**：同一对图片多次调用，结果是否一致

## 💡 Prompt 工程心得（边做边记）

### 已知坑（提前预警）
- 视觉 LLM 偶尔会**过度自信**，明明没看清也敢下判断 → 强制要求"看不清就输出无法判断"
- JSON 输出**偶尔会被破坏**（多个引号、半个括号）→ 后端要做 JSON 修复兜底
- 中文场景下，**部分专业术语**（如"网点"、"反差"）AI 可能理解不到位 → 必要时加例子

- [ ] AI 能否区分"印刷差异"和"拍摄角度差异"？
